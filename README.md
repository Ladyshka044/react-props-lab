# My Final React Portfolio

Це фінальний проєкт, що демонструє навички роботи з React, API та Material UI.

### Функціонал:
- **About Me**: Презентація та посилання на репозиторії.
- **My City**: Реальна погода в Києві через OpenWeather API.
- **My Future**: Мотивація та плани розвитку.
- **Технології**: React Router, MUI, Hooks (useState, useEffect).
